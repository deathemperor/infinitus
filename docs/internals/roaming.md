# Roaming between hosts

`packages/client-runtime/src/connection/roaming.ts`, `apps/mobile/src/features/connection/roamingHosts.ts` — pair on one host, connect on another (#663). The server's descriptor may name its other base URLs (`alternateHttpBaseUrls`); the phone keeps them on the bearer profile from the pairing on and re-learns them on every connect, each stored in the profile's normalized shape (`normalizeHttpBaseUrl`), so a pairing made over the alternate itself has no alternate. The server's list replaces the phone's on every connect that names one — it is the authority on its own doors — and a connect that names none keeps what the phone has, minus any `*.trycloudflare.com` name: a quick tunnel the server no longer holds can be handed to anyone, and the bearer token never follows one (a host the profile no longer names is not tried, last-good or not). A connect dials every public host — an https hostname, `isPublicHost` — before every private one (an IP literal, `localhost`, `.local`), so a phone that knows the domain leads with it on the Wi‑Fi too and the LAN address is the fallback, never the first attempt; within a class, the host that worked last, then the paired one, then the alternates. A private host gets the 3 s descriptor wait wherever it stands (on the LAN it answers at once, off it nothing ever does), a public one the default. A host where the server is not — nothing answers (network, timeout), or something else does (`remote-unavailable`, a 404 or another environment's id) — is walked past, one that refuses the credential ends the walk. The bearer session is not host-bound, so no re-pair. The environment row says "Connected via <host>" while the connect landed off the paired host, else "Tries <host> first".

**Nothing fills the list today.** Its one source was the Mac's Cloudflare tunnel (`status.forkTunnel`, through the since-deleted `InfinitusDescriptor.ts`), and that retired with the tunnels: a phone off the Wi‑Fi reaches the environment through Infinitus Connect, whose hostname the client dials directly rather than learning as an alternate. The rules above still hold for any alternate a server does name, and the quick-tunnel guard stays because a profile paired before the retirement can still be carrying one.
