# T3 Timeline P4 — Client-Activity Leases

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Mac only does per-session work (timeline rebuilds for snapshot facts, stats scans, checkpoint snapshots) while some client — a phone, a browser page, or the Mac's own popup — holds a lease on it, so an unattended Mac idles like today.

**Architecture:** `LeaseTable` (Core) keeps `clientId → (scopes, expiresAt)` from `POST /client-activity` reports (T3 `server.reportClientActivity`, `packages/contracts/src/background.ts`: the phone reports every 25 s and on foreground/background with `ttlMs: 45000`, scopes ref-counted from its live subscriptions) and answers `holds(scope)` with a sweep on read. The Mac's popup / pop-out / chat window registers as the local client `"local"` while open. Four call sites are gated; the exporter's facts closure is mine, the other three live in Infi3's files and are handed over as exact snippets.

**Tech Stack:** Swift 6 / SwiftPM, XCTest, Foundation. macOS + Linux.

**Spec:** `docs/superpowers/specs/2026-09-07-t3-timeline-wire-design.md` §4.

```swift
public enum ClientActivity {
    public static let path = "/client-activity"
    public struct Scope: Codable, Sendable, Hashable {
        public enum Kind: String, Codable, Sendable { case sessions, session, fleets, stats }
        public let type: Kind; public let pid: Int32?
        public static let sessions = Scope(type: .sessions, pid: nil), fleets = …, stats = …
        public static func session(_ pid: Int32) -> Scope
    }
    public struct Report: Codable, Sendable, Equatable {
        public let clientId: String; public let visible: Bool; public let focused: Bool
        public let recentlyInteracted: Bool; public let scopes: [Scope]; public let ttlMs: Int
    }
    public static let ttlCapMs = 300_000   // a client can't lease more than 5 min at a time
    public static let localClientId = "local"
}
public final class LeaseTable: @unchecked Sendable {
    public init()
    public func report(_ r: ClientActivity.Report, now: Date = Date())
    public func release(clientId: String)
    /// `session(pid)` is held by a `sessions` lease too; sweeps expired clients first.
    public func holds(_ scope: ClientActivity.Scope, now: Date = Date()) -> Bool
    public func leasedPids(now: Date = Date()) -> Set<Int32>?   // nil = every pid (a `sessions` lease)
    public func clientCount(now: Date = Date()) -> Int
}
```
