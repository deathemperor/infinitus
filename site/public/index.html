Two or more Claude subscriptions? Infinitus is mission control for a fleet of Claude Code accounts. It watches every usage window, rotates to the freshest account the moment a limit hits, and nudges your stopped sessions back to work — so an agent run survives the five-hour wall without you.

How it works

A native Swift app over the claude-swap engine. Every engine touchpoint is an isolated cswap --json subprocess — Infinitus never touches your credentials directly.

01 · WATCH

Every window, every account

5-hour, weekly, and per-model usage gauges with reset clocks, pace markers, and a flash warning when an account is dying.

02 · SWITCH

Rotate on the limit, not after it

Consume-first auto-switch picks the account whose weekly window resets soonest. Limits become a hand-off, not an outage.

03 · RESUME

Sessions pick themselves back up

Stopped Claude Code sessions get a resume nudge on the fresh account — with guards so a mid-turn session is never interrupted.

The popup

The whole fleet in one glance — RPG theme shown: MP is your 5-hour window, HP the weekly, Dragon the per-model quota. Skulls are limited accounts; the crown is who's carrying.

Features

Built for people who run agents all day and want to look at one thing — briefly — when it matters.

Watch & switch

●Session progress

Zero-token transcript parsing shows what every agent is doing: current task, todo progress, quiet time, retry trouble.

●Resume guards

Evidence-gated nudges: only after a real switch or a fresh capacity verdict, never into a busy session, with cooldowns.

●All-dead countdown

When every account is limited, a giant countdown to the first revival — and how many sessions are waiting on it.

●At this pace

Measured burn per window, when each runs out, when the whole fleet is out — and a full forecast dashboard behind it.

●Reset battle plans

The smart engine triggers 5-hour windows deliberately, chaining two sessions back-to-back on the same account.

●Session narration

Optional one-line Claude summaries of what each agent is doing — off by default, strictly budgeted, only while you're looking.

●One account, done right

Single account? A card with big gauges and the reset time in the menu bar — no fleet vocabulary until you add a second.

Phone

●Mobile companion

Your fleet on the iPhone — over Wi-Fi, Tailscale, your own Cloudflare hostname or a free quick tunnel. One QR, every route; the Mac lists which devices are connected and how.

●Session chat

Every session as a chat on the phone: markdown replies streamed live, tool runs in one chip, sub-agent cards. Answer prompts, reply, attach photos from the camera or files, or share an image from any app's Share sheet straight into a session.

●Live Activities

Working sessions in the Dynamic Island; when everything is limited, a lock-screen revival countdown that ticks natively. With an APNs key on the Mac they keep moving with the app closed.

●Game HUD chat header

A ringed portrait with the level on its rim, a name plate, HP/MP-style bars and a buff square per model — or a compact header, or a stat strip. Every style previews live in your theme.

●Crash reports, on-device

The phone app and the Mac app record their own crashes into Settings. Nothing leaves your machine; any report can go into a session's chat for triage.

●Widgets in your theme

Home-screen and lock-screen widgets draw the active account's windows as your theme names and colors them, what's waiting on you, and the revival countdown when every account is limited.

●AWS login from the phone

A session stuck on an expired aws login shows up on your phone; sign in there (passkeys included) and the session is told to carry on.

●Sessions first

The phone opens on what's waiting for you; unnamed sessions get a Haiku title that follows the work; one Continue button for a session a limit or a crash stopped.

●Capture into a session

On the Mac, Capture Screen for a Session… takes a region or a window, a session, a note. On the phone, Share → Infinitus from any app does the same.

●Dictate in any language

Vietnamese in, English out — translated on the phone, or sent as spoken with a note asking for an English reply. The recognizer knows your session's terms.

Where the effort went, per activity, model, engine (Claude Code, Codex CLI) and effort setting. A tokens/min record book: daily peaks, the all-time best, the trend.

The wall

Point a spare display at your fleet. When agents are working, a session board shows each one's repo, current task, and todo progress. When everything is limited, the revival countdown takes the room. When nothing is happening — it's dark, on purpose.

You only need to look when something is moving. That's the whole idea.

Install

Grab a release or build from source — it's a plain SwiftPM project.

macOS

# Homebrew
brew install --cask deathemperor/tap/infinitus

# or grab Infinitus.app from the latest release
open https://github.com/deathemperor/infinitus/releases

# or build it yourself
git clone https://github.com/deathemperor/infinitus
cd infinitus && ./make-app.sh && open Infinitus.app

Releases are Developer ID signed and notarized (nightlies are not: right-click → Open once). Requires the claude-swap CLI on your PATH; Infinitus walks you through first-account setup.

Linux (Omarchy / Arch)

# tray daemon + Quickshell panel plugin
git clone https://github.com/deathemperor/infinitus
cd infinitus
swift build -c release --product infinitus-tray
# panel: packaging/omarchy/quickshell-plugin/

Same core, same gauges — rendered in your Quickshell bar. On the AUR.

Questions

What is Infinitus?
A free, open-source menu bar app (macOS) and tray daemon + panel plugin (Linux) that manages a fleet of Claude Code accounts: every account's 5-hour, weekly and per-model usage at a glance, automatic rotation to the freshest account when a limit hits, and resume nudges that put stopped sessions back to work.
Does it work with Claude Code?
Yes. It reads Claude Code's own local session files to show progress and switches accounts through the claude-swap CLI. It never modifies Claude Code.
Which platforms?
macOS 14+ on Apple silicon (Homebrew cask), and Linux — a static infinitus-tray for x86_64 and aarch64 with a Quickshell panel plugin for Omarchy / Arch (also on the AUR). The iPhone companion builds from source today — no App Store build yet.
Is it free?
Free and open source, MIT licensed. Source is on GitHub.
Are the numbers exact?
Usage percentages come from Anthropic's own limits reporting. Usage-cost figures are estimates, never billing truth.
